12@check(code="SO005") 

13def check_duplicate_sources(source, ctx): 

14 """Sources must not share the same database relation. 

15 

16 !!! info "Rationale" 

17 

18 Two source definitions pointing at the same physical table cause ambiguous lineage and divergent staging logic. Different staging models may apply conflicting transformations to the same raw data, leading to inconsistent results. This check ensures every database relation is claimed by exactly one source definition. 

19 

20 Receives: 

21 source (SourceNode): The SourceNode object to check. 

22 sources (list[SourceNode]): List of SourceNode objects parsed from `manifest.json`. 

23 

24 Other Parameters: 

25 description (str | None): Description of what the check does and why it is implemented. 

26 exclude (str | list[str] | None): Regex pattern(s) to match the source path (i.e the .yml file where the source is configured). Source paths that match any pattern will not be checked. 

27 include (str | list[str] | None): Regex pattern(s) to match the source path (i.e the .yml file where the source is configured). Only source paths that match any pattern will be checked. 

28 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

29 

30 Example(s): 

31 ```yaml 

32 manifest_checks: 

33 - name: check_duplicate_sources 

34 ``` 

35 

36 """

38 def _node(s): 

39 """Return the SourceNode from either a SourceWrapper or a DictProxy. 

40 

41 In a live runner ctx.sources contains SourceWrapper objects (SimpleNamespace 

42 with a .source attribute). In unit-test helpers ctx.sources items are 

43 DictProxy objects with direct field access. The None-fallback handles both. 

44 

45 Returns: 

46 The unwrapped source node object with direct field access. 

47 

48 """ 

49 inner = getattr(s, "source", None) 

50 return inner if inner is not None else s 

51 

52 src_node = _node(source) 

53 src_rel = (src_node.database, src_node.schema, src_node.identifier) 

54 dupes = [ 

55 uid 

56 for uid in ctx.sources_by_relation.get(src_rel, []) 

57 if uid != src_node.unique_id 

58 ] 

59 if dupes: 

60 fail( 

61 f"Source `{source.source_name}.{source.name}` shares its relation ({src_rel}) with: {dupes}." 

62 )

65@check(code="SO006") 

66def check_source_min_downstream_models( 

67 source, ctx, *, min_number_of_models: Annotated[int, Field(gt=0)] = 1 

68): 

69 """Sources must be referenced by at least the specified number of models. 

70 

71 !!! info "Rationale" 

72 

73 Some sources are expected to feed multiple downstream models — for example, a raw events table that drives both a sessions model and a revenue model. Requiring a minimum number of consumers guards against accidental under-use and ensures that critical source data is fully exploited in the project's lineage. 

74 

75 With the default `min_number_of_models` of 1 this check is equivalent to `check_source_not_orphaned`; prefer that check if you only need to assert a source is referenced at least once, and use this check when you want to require a higher minimum. 

76 

77 Parameters: 

78 min_number_of_models (int): Minimum number of models that must reference the source. Must be greater than 0. 

79 

80 Receives: 

81 models (list[ModelNode]): List of ModelNode objects parsed from `manifest.json`. 

82 source (SourceNode): The SourceNode object to check. 

83 

84 Other Parameters: 

85 description (str | None): Description of what the check does and why it is implemented. 

86 exclude (str | list[str] | None): Regex pattern(s) to match the source path (i.e the .yml file where the source is configured). Source paths that match any pattern will not be checked. 

87 include (str | list[str] | None): Regex pattern(s) to match the source path (i.e the .yml file where the source is configured). Only source paths that match any pattern will be checked. 

88 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

89 

90 Example(s): 

91 ```yaml 

92 manifest_checks: 

93 - name: check_source_min_downstream_models 

94 ``` 

95 ```yaml 

96 manifest_checks: 

97 - name: check_source_min_downstream_models 

98 min_number_of_models: 2 

99 ``` 

100 

101 """ 

102 n = len(ctx.children_by_unique_id.get(source.unique_id, [])) 

103 if n < min_number_of_models: 

104 fail( 

105 f"Source `{source.source_name}.{source.name}` is referenced by {n} model(s), fewer than the minimum {min_number_of_models}." 

106 )

109@check(code="SO007") 

110def check_source_not_orphaned(source, ctx): 

111 """Sources must be referenced in at least one model. 

112 

113 !!! info "Rationale" 

114 

115 An orphaned source — one that is declared in the project but never referenced by any model — is a maintenance liability. It adds noise to the project's source catalogue, may represent a data feed that is no longer needed, and can mislead new team members into thinking data is being used when it is not. This check keeps the source catalogue clean by flagging any source that has no downstream consumers, prompting teams to either wire it into the lineage graph or remove it. 

116 

117 Receives: 

118 models (list[ModelNode]): List of ModelNode objects parsed from `manifest.json`. 

119 source (SourceNode): The SourceNode object to check. 

120 

121 Other Parameters: 

122 description (str | None): Description of what the check does and why it is implemented. 

123 exclude (str | list[str] | None): Regex pattern(s) to match the source path (i.e the .yml file where the source is configured). Source paths that match any pattern will not be checked. 

124 include (str | list[str] | None): Regex pattern(s) to match the source path (i.e the .yml file where the source is configured). Only source paths that match any pattern will be checked. 

125 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

126 

127 Example(s): 

128 ```yaml 

129 manifest_checks: 

130 - name: check_source_not_orphaned 

131 ``` 

132 

133 """ 

134 num_refs = len(ctx.children_by_unique_id.get(source.unique_id, [])) 

135 if num_refs < 1: 

136 fail( 

137 f"Source `{source.source_name}.{source.name}` is orphaned, i.e. not referenced by any model."

141@check(code="SO008") 

142def check_source_used_by_models_in_same_directory(source, ctx): 

143 """Sources can only be referenced by models that are located in the same directory where the source is defined. 

144 

145 !!! info "Rationale" 

146 

147 dbt's best-practice project structure places source definitions alongside the staging models that consume them. When a model in a distant directory references a source, it breaks this colocation principle, making it harder to understand which models own which sources and causing confusion about where raw-to-staged transformations live. Enforcing same-directory usage keeps source ownership explicit and the staging layer well-bounded. 

148 

149 Receives: 

150 source (SourceNode): The SourceNode object to check. 

151 

152 Other Parameters: 

153 description (str | None): Description of what the check does and why it is implemented. 

154 exclude (str | list[str] | None): Regex pattern(s) to match the source path (i.e the .yml file where the source is configured). Source paths that match any pattern will not be checked. 

155 include (str | list[str] | None): Regex pattern(s) to match the source path (i.e the .yml file where the source is configured). Only source paths that match any pattern will be checked. 

156 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

157 

158 Example(s): 

159 ```yaml 

160 manifest_checks: 

161 - name: check_source_used_by_models_in_same_directory 

162 ``` 

163 

164 """ 

165 source_dir = PurePosixPath(clean_path_str(source.original_file_path)).parent 

166 reffed_models_not_in_same_dir = [ 

167 m.name 

168 for m in ctx.children_by_unique_id.get(source.unique_id, []) 

169 if PurePosixPath(clean_path_str(m.original_file_path)).parent != source_dir 

170 ] 

171 

172 if len(reffed_models_not_in_same_dir) != 0: 

173 fail( 

174 f"Source `{source.source_name}.{source.name}` is referenced by models defined in a different directory: {reffed_models_not_in_same_dir}" 

175 )

178@check(code="SO009") 

179def check_source_used_by_only_one_model(source, ctx): 

180 """Each source can be referenced by a maximum of one model. 

181 

182 !!! info "Rationale" 

183 

184 A common dbt best practice is to have a single staging model per source table, acting as the sole entry point that applies initial cleaning, renaming, and casting. When multiple models reference the same source directly, that cleaning logic is duplicated or diverges, leading to inconsistent representations of the same raw data across the project. Enforcing a single consumer per source encourages the staging-layer pattern and makes it clear where the authoritative transformation of each source lives. 

185 

186 Receives: 

187 models (list[ModelNode]): List of ModelNode objects parsed from `manifest.json`. 

188 source (SourceNode): The SourceNode object to check. 

189 

190 Other Parameters: 

191 description (str | None): Description of what the check does and why it is implemented. 

192 exclude (str | list[str] | None): Regex pattern(s) to match the source path (i.e the .yml file where the source is configured). Source paths that match any pattern will not be checked. 

193 include (str | list[str] | None): Regex pattern(s) to match the source path (i.e the .yml file where the source is configured). Only source paths that match any pattern will be checked. 

194 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

195 

196 Example(s): 

197 ```yaml 

198 manifest_checks: 

199 - name: check_source_used_by_only_one_model 

200 ``` 

201 

202 """ 

203 num_refs = len(ctx.children_by_unique_id.get(source.unique_id, [])) 

204 if num_refs > 1: 

205 fail( 

206 f"Source `{source.source_name}.{source.name}` is referenced by more than one model."
