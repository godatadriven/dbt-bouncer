4@check(code="CA004") 

5def check_source_columns_are_all_documented( 

6 catalog_source, ctx, *, case_sensitive: bool = True 

7): 

8 """All columns in a source should be included in the source's properties file, i.e. `.yml` file. 

9 

10 !!! info "Rationale" 

11 

12 Source tables are the entry point for raw data into a dbt project. When a column exists in the database but is absent from the source properties file, it cannot have a description, a freshness check, or a data test applied to it. Over time, undocumented columns accumulate silently, making it harder to understand what data is available and creating blind spots in data quality monitoring. This check enforces full column coverage so that every raw field is explicitly acknowledged and can be tested or documented. 

13 

14 Parameters: 

15 case_sensitive (bool): Whether the column names are case sensitive or not. Necessary for adapters like `dbt-snowflake` where the column in `catalog.json` is uppercase but the column in `manifest.json` can be lowercase. Defaults to `false` for `dbt-snowflake`, otherwise `true`. 

16 

17 Receives: 

18 catalog_source (CatalogNodeEntry): The CatalogNodeEntry object to check. 

19 manifest_obj (ManifestObject): The ManifestObject object parsed from `manifest.json`. 

20 sources (list[SourceNode]): List of SourceNode objects parsed from `catalog.json`. 

21 

22 Other Parameters: 

23 description (str | None): Description of what the check does and why it is implemented. 

24 exclude (str | list[str] | None): Regex pattern(s) to match the source path (i.e the .yml file where the source is configured). Source paths that match any pattern will not be checked. 

25 include (str | list[str] | None): Regex pattern(s) to match the source path (i.e the .yml file where the source is configured). Only source paths that match any pattern will be checked. 

26 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

27 

28 Example(s): 

29 ```yaml 

30 catalog_checks: 

31 - name: check_source_columns_are_all_documented 

32 ``` 

33 

34 """ 

35 # `ctx.sources` holds wrapped source objects (the real SourceNode nested 

36 # under a `.source` attribute) in a live runner, so read the unwrapped 

37 # source from `sources_by_unique_id`, mirroring how the catalog column 

38 # checks read models from `models_by_unique_id`. The unit-test harness 

39 # leaves that lookup empty, so fall back to the flat `ctx.sources` list it 

40 # builds instead. 

41 sources_by_id = ( 

42 ctx.sources_by_unique_id 

43 if ctx.sources_by_unique_id 

44 else {s.unique_id: s for s in ctx.sources} 

45 ) 

46 source = sources_by_id.get(catalog_source.unique_id) 

47 if source is None: 

48 # A catalog source with no matching manifest source has no documented 

49 # columns to compare against, so skip it rather than crash. This 

50 # mirrors how the catalog column checks skip a catalog node that is not 

51 # a model. In practice catalog.json sources are derived from the 

52 # manifest, so this is a defensive guard. 

53 return 

54 

55 if ctx.manifest_obj.manifest.metadata.adapter_type in ["snowflake"]: 

56 case_sensitive = False 

57 

58 source_columns = source.columns or {} 

59 if case_sensitive: 

60 undocumented_columns = [ 

61 v.name 

62 for _, v in catalog_source.columns.items() 

63 if v.name not in source_columns 

64 ] 

65 else: 

66 source_columns_lower = {c.lower() for c in source_columns} 

67 undocumented_columns = [ 

68 v.name 

69 for _, v in catalog_source.columns.items() 

70 if v.name.lower() not in source_columns_lower 

71 ] 

72 

73 if undocumented_columns: 

74 fail( 

75 f"`{catalog_source.unique_id}` has columns that are not included in the sources properties file: {undocumented_columns}" 

76 )
