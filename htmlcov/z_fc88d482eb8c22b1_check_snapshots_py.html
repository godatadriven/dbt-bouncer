17@check(code="SN001") 

18def check_snapshot_description_populated( 

19 snapshot, *, min_description_length: Annotated[int, Field(gt=0)] | None = None 

20): 

21 """Snapshots must have a populated description. 

22 

23 !!! info "Rationale" 

24 

25 Snapshots capture slowly-changing dimension (SCD) history and represent some of the most business-critical data in a dbt project. Without descriptions, it is unclear what entity a snapshot tracks, what the key fields represent, or how frequently it is refreshed — information that is essential for analysts interpreting historical data and for engineers maintaining the snapshot strategy. 

26 

27 Parameters: 

28 min_description_length (int | None): Minimum length required for the description to be considered populated. 

29 

30 Receives: 

31 snapshot (SnapshotNode): The SnapshotNode object to check. 

32 

33 Other Parameters: 

34 description (str | None): Description of what the check does and why it is implemented. 

35 exclude (str | list[str] | None): Regex pattern(s) to match the snapshot path. Snapshot paths that match any pattern will not be checked. 

36 include (str | list[str] | None): Regex pattern(s) to match the snapshot path. Only snapshot paths that match any pattern will be checked. 

37 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

38 

39 Example(s): 

40 ```yaml 

41 manifest_checks: 

42 - name: check_snapshot_description_populated 

43 ``` 

44 ```yaml 

45 manifest_checks: 

46 - name: check_snapshot_description_populated 

47 min_description_length: 25 # Setting a stricter requirement for description length 

48 ``` 

49 

50 """ 

51 if not is_description_populated( 

52 snapshot.description or "", min_description_length or 4 

53 ): 

54 fail( 

55 f"`{get_clean_model_name(snapshot.unique_id)}` does not have a populated description." 

56 )

76 Other Parameters: 

77 description (str | None): Description of what the check does and why it is implemented. 

78 exclude (str | list[str] | None): Regex pattern(s) to match the snapshot path. Snapshot paths that match any pattern will not be checked. 

79 include (str | list[str] | None): Regex pattern(s) to match the snapshot path. Only snapshot paths that match any pattern will be checked. 

80 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

81 

82 Example(s): 

83 ```yaml 

84 manifest_checks: 

85 - name: check_snapshot_has_meta_keys 

86 keys:

88 - owner 

89 ```

100@check(code="SN003") 

101def check_snapshot_has_tags( 

102 snapshot, *, criteria: Criteria = Criteria.ALL, tags: list[str] 

103): 

104 """Snapshots must have the specified tags. 

105 

106 !!! info "Rationale" 

107 

108 Tags on snapshots enable selective execution (e.g. `dbt snapshot --select tag:nightly`) and make it possible to apply governance policies to specific groups of snapshots. Without enforced tagging, snapshots can be inadvertently skipped in scheduled runs or included in the wrong execution contexts, leading to stale historical data. 

109 

110 Parameters: 

111 criteria (Literal["all", "any", "one"]): Whether the snapshot must have any, all, or exactly one of the specified tags. Default: `all`. 

112 tags (list[str]): List of tags to check for. 

113 

114 Receives: 

115 snapshot (SnapshotNode): The SnapshotNode object to check. 

116 

117 Other Parameters: 

118 description (str | None): Description of what the check does and why it is implemented. 

119 exclude (str | list[str] | None): Regex pattern(s) to match the snapshot path. Snapshot paths that match any pattern will not be checked. 

120 include (str | list[str] | None): Regex pattern(s) to match the snapshot path. Only snapshot paths that match any pattern will be checked. 

121 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

122 

123 Example(s): 

124 ```yaml 

125 manifest_checks: 

126 - name: check_snapshot_has_tags 

127 tags: 

128 - tag_1 

129 - tag_2 

130 ``` 

131 

132 """ 

133 resource_tags = snapshot.tags or [] 

134 match criteria: 

135 case Criteria.ANY: 

136 if not any(tag in resource_tags for tag in tags): 

137 fail( 

138 f"`{snapshot.name}` does not have any of the required tags: {tags}." 

139 ) 

140 case Criteria.ALL: 

141 missing_tags = [tag for tag in tags if tag not in resource_tags] 

142 if missing_tags: 

143 fail(f"`{snapshot.name}` is missing required tags: {missing_tags}.") 

144 case Criteria.ONE if sum(tag in resource_tags for tag in tags) != 1: 

145 fail( 

146 f"`{snapshot.name}` must have exactly one of the required tags: {tags}." 

147 )

150@check(code="SN004") 

151def check_snapshot_has_unique_key(snapshot): 

152 """Snapshots must have a `unique_key` configured. 

153 

154 !!! info "Rationale" 

155 

156 The `unique_key` configuration is essential for snapshot correctness — dbt uses it to identify existing rows when deciding whether to insert a new record or close an old one. Without a `unique_key`, dbt cannot reliably track which rows have changed, leading to duplicate history records or missed updates that silently corrupt the slowly-changing dimension table. 

157 

158 Receives: 

159 snapshot (SnapshotNode): The SnapshotNode object to check. 

160 

161 Other Parameters: 

162 description (str | None): Description of what the check does and why it is implemented. 

163 exclude (str | list[str] | None): Regex pattern(s) to match the snapshot path. Snapshot paths that match any pattern will not be checked. 

164 include (str | list[str] | None): Regex pattern(s) to match the snapshot path. Only snapshot paths that match any pattern will be checked. 

165 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

166 

167 Example(s): 

168 ```yaml 

169 manifest_checks: 

170 - name: check_snapshot_has_unique_key 

171 ``` 

172 

173 """ 

174 config = snapshot.config 

175 if not (config and getattr(config, "unique_key", None)): 

176 fail( 

177 f"`{get_clean_model_name(snapshot.unique_id)}` does not have a `unique_key` configured." 

178 )

181@check(code="SN005") 

182def check_snapshot_names(snapshot, *, snapshot_name_pattern: RegexPattern): 

183 """Snapshots must have a name that matches the supplied regex. 

184 

185 !!! info "Rationale" 

186 

187 A consistent naming convention for snapshots (e.g. a domain prefix like `erp_` or a suffix like `_snapshot`) makes it immediately obvious in the warehouse that a table is a point-in-time history capture rather than a regular dimension or fact. Without naming conventions, snapshots can be confused with other tables, leading to incorrect use or accidental truncation. 

188 

189 Parameters: 

190 snapshot_name_pattern (str): Regexp the snapshot name must match. 

191 

192 Receives: 

193 snapshot (SnapshotNode): The SnapshotNode object to check. 

194 

195 Other Parameters: 

196 description (str | None): Description of what the check does and why it is implemented. 

197 exclude (str | list[str] | None): Regex pattern(s) to match the snapshot path. Snapshot paths that match any pattern will not be checked. 

198 include (str | list[str] | None): Regex pattern(s) to match the snapshot path. Only snapshot paths that match any pattern will be checked. 

199 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

200 

201 Example(s): 

202 ```yaml 

203 manifest_checks: 

204 - name: check_snapshot_names 

205 include: ^snapshots/erp 

206 snapshot_name_pattern: ^erp 

207 ``` 

208 

209 """ 

210 compiled_pattern = compile_pattern(snapshot_name_pattern.strip()) 

211 if compiled_pattern.match(str(snapshot.name)) is None: 

212 fail( 

213 f"`{snapshot.name}` does not match the supplied regex `{snapshot_name_pattern.strip()}`." 

214 )

217@check(code="SN006") 

218def check_snapshot_strategy( 

219 snapshot, 

220 *, 

221 allowed_strategies: list[str] = ["check", "timestamp"], # ruff: ignore[mutable-argument-default] 

222): 

223 """Snapshots must use an allowed strategy and have the required strategy-specific configuration. 

224 

225 !!! info "Rationale" 

226 

227 The snapshot strategy determines how dbt detects row changes. Using an unsupported or misconfigured strategy can lead to incorrect history capture: the `timestamp` strategy requires an `updated_at` column to detect changes, and the `check` strategy requires `check_cols` to define which columns to monitor. Enforcing both the allowed strategies and their required fields prevents silent data quality issues in slowly-changing dimension tables. 

228 

229 Parameters: 

230 allowed_strategies (list[str]): List of permitted snapshot strategies. Default: `["check", "timestamp"]`. 

231 

232 Receives: 

233 snapshot (SnapshotNode): The SnapshotNode object to check. 

234 

235 Other Parameters: 

236 description (str | None): Description of what the check does and why it is implemented. 

237 exclude (str | list[str] | None): Regex pattern(s) to match the snapshot path. Snapshot paths that match any pattern will not be checked. 

238 include (str | list[str] | None): Regex pattern(s) to match the snapshot path. Only snapshot paths that match any pattern will be checked. 

239 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

240 

241 Example(s): 

242 ```yaml 

243 manifest_checks: 

244 - name: check_snapshot_strategy 

245 ``` 

246 ```yaml 

247 manifest_checks: 

248 - name: check_snapshot_strategy 

249 allowed_strategies: 

250 - timestamp # Only allow the timestamp strategy 

251 ``` 

252 

253 """ 

254 config = snapshot.config 

255 strategy = getattr(config, "strategy", None) if config else None 

256 if strategy not in allowed_strategies: 

257 fail( 

258 f"`{get_clean_model_name(snapshot.unique_id)}` has strategy `{strategy}`, which is not one of the allowed strategies: {allowed_strategies}." 

259 ) 

260 if strategy == "timestamp" and not getattr(config, "updated_at", None): 

261 fail( 

262 f"`{get_clean_model_name(snapshot.unique_id)}` uses the `timestamp` strategy but has no `updated_at` configured." 

263 ) 

264 if strategy == "check" and not getattr(config, "check_cols", None): 

265 fail( 

266 f"`{get_clean_model_name(snapshot.unique_id)}` uses the `check` strategy but has no `check_cols` configured." 

267 )
