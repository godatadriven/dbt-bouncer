1"""Source checks that use the dbt Information Schema.""" 

2 

3from dbt_bouncer.check_framework.decorator import check, fail 

4 

5 

6@check(code="IS009") 

7def check_source_columns_are_used(source, ctx): 

8 """Every column declared on a source must be used by at least one downstream model. 

9 

10 !!! info "Rationale" 

11 

12 Source YAML is often generated once and never pruned, so it documents, tests and sometimes loads columns that no model reads. Unused columns cost ingestion and test time, and they suggest to readers that the data is in use. dbt's column-level lineage shows which source columns models actually read, so this check can list the declared columns that nothing uses. 

13 

14 !!! note 

15 

16 This check requires the dbt Information Schema (dbt 2.0+, `--generate-info-schema`). A column counts as used when any lineage edge reads it, including joins and filters. When a downstream model has no column-level lineage (dbt's static analysis could not analyse it), the source is not checked, because its columns cannot be proven unused. Ephemeral downstream models are the exception: dbt records their lineage on the models that select from them. Sources without downstream models are not checked: use `check_source_not_orphaned` for those. 

17 

18 Receives: 

19 source (SourceNode): The SourceNode object to check. 

20 

21 Other Parameters: 

22 description (str | None): Description of what the check does and why it is implemented. 

23 exclude (str | list[str] | None): Regex pattern(s) to match the source path. Source paths that match any pattern will not be checked. 

24 include (str | list[str] | None): Regex pattern(s) to match the source path. Only source paths that match any pattern will be checked. 

25 severity (Literal["error", "warn"] | None): Severity level of the check. Default: `error`. 

26 

27 Example(s): 

28 ```yaml 

29 info_schema_checks: 

30 - name: check_source_columns_are_used 

31 ``` 

32 

33 """ 

34 # dbt inlines ephemeral models, so their lineage is recorded on their consumers. 

35 children = [ 

36 child 

37 for child in ctx.children_by_unique_id.get(source.unique_id, []) 

38 if not (child.config and child.config.materialized == "ephemeral") 

39 ] 

40 lineage = ctx.info_schema.lineage_by_child 

41 if not children or any(child.unique_id not in lineage for child in children): 

42 return 

43 used = ctx.info_schema.lineage_parent_columns.get(source.unique_id, set()) 

44 unused = sorted( 

45 name for name in (source.columns or {}) if name.casefold() not in used 

46 ) 

47 if unused: 

48 fail( 

49 f"`{source.unique_id}` declares columns that no model uses: {', '.join(f'`{c}`' for c in unused)}." 

50 )
